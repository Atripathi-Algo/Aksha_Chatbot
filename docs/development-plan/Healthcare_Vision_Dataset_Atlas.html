License risk before anyone starts training

These datasets look usable, but their published terms are research/non-commercial only, or unconfirmed. Using them to train a model that ships in a commercial product is a legal question, not just a technical shortcut — route through IP/compliance before an intern downloads and trains on any of these.

  • CrowdHuman — explicitly non-commercial, redistribution prohibited
  • ShanghaiTech Crowd Counting, PETS2009, Mall Dataset — research-use license, commercial terms unclear
  • RWF-2000 (violence detection) — request-based academic access, no stated commercial terms
  • PSKUS / EDI-RIGA (hand hygiene) — academic license, cite-on-use
  • Medical Waste Dataset 4.0 — referenced in a paper, public download/license status unconfirmed

Recommended intern split for Monday

Ready → build now

Clear data, permissive licenses, fast iteration. Good first assignment — get a baseline model trained and evaluated this week.

Adaptable → second wave

Pair every assignment here with an explicit license-verification task before any training run, plus a plan for hospital-specific fine-tuning data.

No data → reframe the task

Don't send an intern hunting for a dataset that doesn't exist. Reframe as data-collection planning: what footage would need to be captured, from where, under what consent/privacy process.
