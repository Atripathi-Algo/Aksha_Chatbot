3dHandoff notes
Message-type ladder
Consequence sets weight. Answer: 2px grey left rule. Streaming: accent left rule + progress bar. Clarification: 2px accent box on accent-100. Cached: hollow dot + dashed citation chips. Degraded: neutral-200 field, 1px neutral border, correlation ref. Escalation: answer rule + captured-detail table. Approval: the only solid accent band.
MUI tokens
palette.primary.main = #326BC9 (from the app mark), palette.chat.userFill = #e8eaee, palette.chat.rule = #1b2029 at 2px, palette.freshness.live / cached, palette.approval.band. shape.borderRadius = 0 inside the panel only. Frames render 16:9 at 180–200px wide, grayscale.
Keyboard & screen reader
Alt+K opens (focus to input), Esc closes and returns focus to the tab. Tab: scope chips → message list (one stop per message, arrows within) → frames → citation chips → composer → send. Streaming region is aria-live="off"; a polite region announces "answer in progress" once, then the full answer plus source count on completion. Approve is never the first focus stop.
Contrast
Ink #1b2029 on #f4f5f7 = 14.1:1. Accent #326BC9 on the ground = 4.6:1 — passes AA for the 10px chip and label text, unlike the previous red. White on the accent band = 4.6:1, fine for 10px bold and up. Freshness labels use neutral-700 (5.1:1); don't lighten them.

Responsive & accessibility notes
Engineering handoff — decisions, not suggestions.
Breakpoint
Below 1100px the docked panel becomes a bottom sheet at 62% viewport height, not a full-screen overlay: the operator keeps at least two camera tiles visible. Drag handle resizes to 40% / 62% / 88%. Below 600px only, it goes full-screen with a persistent "back to wall" bar.
Keyboard
Alt+K toggles the panel from anywhere; focus lands on the input, Esc returns focus to the launcher tab. Tab order: scope chips → message list (one stop per message, arrow keys move between messages) → citation chips within the focused message → composer → send. Clarification options and Approve/Reject are real buttons in DOM order; Approve is never the first focus stop.
Streaming & screen readers
The streaming region is aria-live="off"; a separate polite live region announces "Answer in progress" once, then the complete answer plus "3 sources" on stream end. Never announce per token. A "read as it arrives" preference exists for users who want aria-live="polite" chunked by sentence.
Contrast flags
Ink #1b2029 on #f4f5f7 = 14.4:1 (pass). Citation chip border and 10px label use full ink, not 60% grey — pass. Flag: accent #326bc9 on the light ground is ~3.4:1 — used only for 2px rules, dots and the white-on-red band (white on #326bc9 = 3.9:1, large/bold text only). Any accent-coloured body copy must drop to --color-accent-700. Freshness labels sit at 60% ink = 4.9:1 — pass, but do not go lighter.
